\section{Evaluation Setup}
\label{sec:eval_setup}

We investigate five research questions:
\begin{itemize}
    \item \textbf{RQ1 (Executable Blame \& Real Git-Tree Replay)}: On 50/50 balanced Python failures, how much accuracy and leave-one-out (LOO) recovery does function-symbol ranking add over a nested file ablation, and what gains hold in a live \texttt{git merge}/\texttt{unittest} queue?
    \item \textbf{RQ2 (End-to-End Queue Performance)}: How does SSMQ compare with static FIFO batching, bridge-safe dependency-aware and FIFO outcome trees, linear trains, fixed-retry batching, and serial queues on throughput, P95 latency, CI cost, and false rejections?
    \item \textbf{RQ3 (Fixed-Density Recall \& Decoupled Risk Controls)}: Holding per-seed conflict counts fixed across $\rho \in [0\%, 100\%]$ (plus $P_c=0$) and breaking risk correlation ($r_{\text{corr}}=0$), where does SSMQ beat static FIFO and where does it reverse?
    \item \textbf{RQ4 (Ablations \& Flaky Trade-Off)}: How much do cone exclusion, risk lanes, and asymmetric gating contribute across $\phi \in [0\%, 15\%]$?
    \item \textbf{RQ5 ($2\times 2$ Factorial Blame Regime)}: At fixed $\rho=80\%$, what macro latency delta does 1-step blame add inside SSMQ across defect density and batch cap, and why?
\end{itemize}

\subsection{86-Batch Symmetrically Balanced Benchmark \& Real Git Replay}
On a six-module Python commerce codebase (\texttt{pricing}, \texttt{inventory}, \texttt{shipping}, \texttt{auth}, \texttt{ledger}, \texttt{checkout}; $13$ functions, $11$ test methods), we execute \BenchTotalBatches{} failing batches (sizes $4$--$8$) via subprocess \texttt{unittest} (enforcing unique hunk match \texttt{count==1} and $\ge 1$ run test): (1)~\BenchSingleBatches{} disjoint regressions ($12$ defects $\times 2$ sizes); (2)~\BenchCommentBatches{} \emph{50/50 counterbalanced comment co-file distractors} ($8$ defects $\times$ both lexical ID polarities, matched churn); (3)~\BenchSiblingBatches{} \emph{50/50 counterbalanced sibling-function co-file distractors} ($11$ pairings $\times$ both ID polarities, matched churn, editing a \emph{different} passing function in the same file); and (4)~\BenchSemBatches{} verified cross-file semantic conflicts ($6$ pairs unit-tested so $A$ and $B$ pass individually while $A{+}B$ fails).

On preloaded fixtures we time five rankers: \texttt{RandomRanker}, \texttt{ChurnRiskRanker}, \texttt{FileRawOverlapRanker}, the strict nested file ablation \texttt{FileTriviaNestedRanker} (sharing our AST comment filter, file/frame weights, and PR-ID tie-break while zeroing only the function-symbol term), and \texttt{ASTStackCausalRanker} (Algorithm~\ref{alg:blame}), running subprocess LOO verification (\texttt{unittest} on $B\setminus\{s_1\}$) for \emph{all five rankers} on every batch. To test exact-Git-tree execution without synthetic oracles (\texttt{v5\_exp10\_real\_git\_replay}), we replay 10 paired 12-PR streams (1 semantic conflict pair, 2 defects, 8 clean/sibling PRs) in temporary Git repositories via live \texttt{git merge --no-edit}, \texttt{python3 -B -m unittest}, and \texttt{ASTStackCausalRanker} ($K_{\max}=4$), verifying final \texttt{main} passes \texttt{unittest}.

\subsection{Trace Replay, Fixed-Density Oracle, and Decoupled Controls}
Our discrete-event simulator replays the 600 consecutive PRs in Table~\ref{tab:trace_summary}: the earliest $25\%$ ($50$~PRs/repo) form the leak-free warm-up prefix for $\hat{G}$, P90 scales, and \texttt{warmup\_mean\_risk}; the remaining $75\%$ ($450$ evaluation PRs) drive arrivals at $6.0\times v$~PR/h ($v\in\{1\times, 3\times, 5\times, 10\times\}$). Runs use $W=8$ workers ($W=1$ for \texttt{SerialQueue}), CI durations $\mathcal{N}(12.0, 2.0^2)$~min (floored at $0.01$~min), $8\%$ target mean defect rate, RQ1 Top-1/Top-2 accuracy (Top-2 capped at $0.99$), and a frozen $0.00004$~min ($\approx 2.4$~ms) overhead for bit-exact determinism.

To hold conflict density constant per paired seed, \texttt{build\_ground\_truth} fixes target count $M$ to the baseline on-graph draw ($P_c=0.18$). For $\rho<1$, it retains $\text{round}(\rho M)$ visible edges without replacement and samples $M-k$ disjoint off-graph pairs via weighted A-Res ($4\times$ same-root weight; saturating only where dense \texttt{TypeScript} exhausts disjoint pairs at $\rho \le 0.40$); $3\%$ of conflicts are persistent. Suite \texttt{v5\_exp9\_decoupled\_sens} sets $r_{\text{corr}}=0$ (uniform $8\%$ defects uncorrelated with $r(p)$) at $\rho \in \{0\%, 40\%, 80\%\}$.

\subsection{Baselines, Ablations, and Statistical Protocol}
We compare seven schedulers and six ablations: \texttt{SerialQueue} ($W=1$), \texttt{StaticBatchBisect} (FIFO, $K_{\max}=8$, bisection~\cite{fallahzadeh2023accelerating}), \texttt{SpeculativeLinear} (FIFO train, $D_{\max}=4$), \texttt{FIFOOutcomeTree} (FIFO pass/fail tree charging partial cancel time), \texttt{DepAwareOutcomeTree} (conflict-graph outcome-tree proxy after SubmitQueue~\cite{ananthanarayanan2019keeping} with disjoint lanes and a strict barrier holding any bridge PR overlapping $\ge 2$ active lanes until active lanes remain pairwise cone-disjoint, under warm-up cones, synthetic priors, and constant-mean CI), \texttt{FlakeAwareBatch} (FIFO + 1 unconditional retry~\cite{henderson2023flake}), and ablations \texttt{SSMQ-NoCone} (no cone exclusion or overlap promotion), \texttt{SSMQ-NoRisk} (no risk cutoff), \texttt{SSMQ-NoGraph} (FIFO), \texttt{SSMQ-NoFlaky}, \texttt{SSMQ-FixedRetry} (matched 1-retry inside SSMQ), and \texttt{SSMQ-NoBlame}.

\textbf{Metrics and Inference.} P95 and median latencies average per-run merged-PR quantiles; CI cost is runner-min/merged PR; throughput measures finite-burst drain over 150~PRs/repo; invalidations sum canceled runs, stale passes, and confirmed flakes; false rejection divides rejected clean PRs unblocked on current mainline by all intrinsically clean PRs (reported with Defective/Persistent/Flaky counts). Simulation suites run 20 paired seeds/repo (shared nominal blocks; 1 seed in RQ1; 10 paired seeds in Git replay). Table~\ref{tab:main_benchmark} reports $95\%$ marginal bootstrap CIs ($2{,}000$ resamples); contrasts use normal-approximation two-sided paired Wilcoxon tests (zero differences omitted) with Holm-Bonferroni correction ($30$ tests RQ2; $4$ RQ5), $2{,}000$-resample paired bootstrap differences, and Cliff's $|\delta|$, conditional on the three OSS traces. Twenty-seed A/A drift (\texttt{v5\_exp1\_aa\_noise}) is \AANoiseThroughputPct{}\% throughput, \AANoiseLatencyPct{}\% P95, and \AANoiseComputePct{}\% cost.
