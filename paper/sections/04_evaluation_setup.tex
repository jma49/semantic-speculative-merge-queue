\section{Evaluation Setup}
\label{sec:eval_setup}

We investigate five research questions:
\begin{itemize}
    \item \textbf{RQ1 (Executable Attribution)}: How accurately and fast does \texttt{ASTStackCausalRanker} isolate regressions, comment distractors, \emph{functional sibling-function co-file edits}, and semantic conflicts on executed Python failures vs.\ a same-information trivia-filtered file ranker?
    \item \textbf{RQ2 (End-to-End Performance)}: How does SSMQ compare against static FIFO batching, dependency-aware and FIFO outcome trees, linear trains, fixed-retry batching, and serial queues across throughput, survivor P95 latency, CI cost, and clean-PR rejections?
    \item \textbf{RQ3 (Fixed-Density Non-Circularity)}: Holding total conflict count fixed, do SSMQ's gains hold for $\rho \in [40\%, 100\%]$, and what occurs at zero conflict ($P_c=0$)?
    \item \textbf{RQ4 (Deconfounded Ablations \& Flaky Gating)}: How much do cone disjointness, risk lanes, and matched retry rules each contribute across $\phi \in [0\%, 15\%]$?
    \item \textbf{RQ5 ($2\times 2$ Factorial Blame Regime)}: At fixed $\rho$, how much end-to-end latency gain does 1-step blame add inside SSMQ across defect density and batch cap, and why?
\end{itemize}

\subsection{Executable 80-Batch Python Blame Benchmark}
We build a six-module Python commerce codebase (\texttt{pricing}, \texttt{inventory}, \texttt{shipping}, \texttt{auth}, \texttt{ledger}, \texttt{checkout}; $13$ functions, $11$ test methods) and run \BenchTotalBatches{} failing batches (sizes $4$--$8$) via subprocess \texttt{unittest}, raising errors on any unmatched patch (zero silent skips):
\begin{enumerate}
    \item \textbf{\BenchSingleBatches{} Disjoint Regressions}: $12$ defects across all six modules bundled with benign functional-AST PRs.
    \item \textbf{\BenchCommentBatches{} Comment Co-File Distractors}: Each defect paired with a comment-only edit in the identical file.
    \item \textbf{\BenchSiblingBatches{} Functional Sibling-Function Co-File Distractors}: Executable edits to a \emph{different} passing function in the \emph{same file} as the defect, with balanced line churn and counterbalanced PR IDs so file overlap, comment filtering, and ID tie-breaks cannot separate them.
    \item \textbf{\BenchSemBatches{} Pairwise Semantic Conflicts}: $6$ cross-file pairs unit-tested so \emph{PR~$A$ passes alone, PR~$B$ passes alone, and $A+B$ fails}.
\end{enumerate}
We time five deterministic rankers on preloaded fixture strings: \texttt{RandomRanker}, \texttt{ChurnRiskRanker}, \texttt{FileRawOverlapRanker} (traceback file + test-to-file specificity without comment filtering), \texttt{FileTriviaFilteredRanker} (identical AST comment filter and file specificity as ours, differing \emph{solely} in file vs.\ function granularity), and \texttt{ASTStackCausalRanker} (Algorithm~\ref{alg:blame}). Beyond Top-1/Top-2/MRR, we run a subprocess \textbf{leave-one-out (LOO) check} (\texttt{unittest} on $B \setminus \{s_1\}$) on all \BenchTotalBatches{} batches to verify 1-step build recovery.

\subsection{Trace Replay and Fixed-Density Conflict Oracle}
Our discrete-event simulator replays all 600 PRs from Table~\ref{tab:trace_summary}: the earliest $25\%$ ($50$~PRs/repo) form the leak-free warm-up prefix for $\hat{G}$, P90 scales, and \texttt{warmup\_mean\_risk}, while the remaining $75\%$ ($450$ evaluation PRs) drive arrivals scaled to mean load $6.0 \times v$~PRs/hr ($v \in \{1\times, 3\times, 5\times, 10\times\}$). Simulations use $W=8$ workers ($W=1$ for \texttt{SerialQueue}), CI runtimes $\mathcal{N}(12.0, 2.0^2)$~min, risk-weighted defect rates with $8\%$ mean target, and blame parameters from RQ1 (\BenchASTTopOnePct{}\% Top-1, \BenchASTTopTwoPct{}\% Top-2 capped at $0.99$ in replay, \BenchASTMs{}~ms).

To decouple recall from conflict density, \texttt{build\_ground\_truth} fixes target budget $M_{\text{target}}$ at the baseline on-graph draw ($P_c=0.18$ over intersecting cones). For $\rho < 1$, each on-graph conflict survives with probability $\rho$, and $M_{\text{target}} - |E_{\text{vis}}|$ replacement conflicts are sampled over \emph{cone-disjoint} pairs (weighted $4\times$ within the same top-level root), keeping total conflicts flat ($\approx \RecallHundredTotalConf{}$--$\RecallFortyTotalConf{}$) across $\rho \in [0.40, 1.00]$; $3\%$ of conflicts are persistent against mainline.

\subsection{Baselines, Deconfounded Ablations, and Statistical Protocol}
We compare seven schedulers and six ablations:
\begin{itemize}
    \item \texttt{SerialQueue} ($W=1$); \texttt{StaticBatchBisect} (FIFO, $K_{\max}=8$, binary bisection~\cite{fallahzadeh2023accelerating}); \texttt{SpeculativeLinear} (FIFO prefix train, $D_{\max}=4$).
    \item \texttt{FIFOOutcomeTree}: FIFO pass/fail outcome-tree proxy ranked by expected merges per CI minute, charging partial cancel time.
    \item \texttt{DepAwareOutcomeTree}: Dependency-aware outcome-tree proxy modeled after SubmitQueue's conflict-graph speculation~\cite{ananthanarayanan2019keeping}, partitioning PRs into cone-overlapping lanes with independent commits across disjoint lanes (using our warm-up cones, synthetic priors, and constant-mean CI duration).
    \item \texttt{FlakeAwareBatch}: FIFO static batching with one unconditional retry (the fixed-retry baseline in~\cite{henderson2023flake}).
    \item \textbf{Deconfounded Ablations}: \texttt{SSMQ-NoCone} (drops cone disjointness), \texttt{SSMQ-NoRisk} (drops risk lanes), \texttt{SSMQ-NoGraph} (drops both), \texttt{SSMQ-NoFlaky} (no retries), \texttt{SSMQ-FixedRetry} (unconditional 1-retry inside SSMQ), and \texttt{SSMQ-NoBlame} (binary bisection).
\end{itemize}

\textbf{Metrics and Inference.} Reported P95 and median latencies average per-run merged-PR quantiles; CI cost is runner-minutes per merged PR; throughput measures finite-burst drain over $150$~PRs/repo; invalidations sum canceled runs, stale passes, and confirmed flakes; false rejection divides clean PRs unblocked against mainline at rejection by all intrinsically clean PRs (reported alongside Defective/Persistent/Flaky counts). Suites run $20$ paired seeds/repo sharing identical fault draws per $(\text{repo}, \text{seed})$ block ($1$ deterministic seed in RQ1; nominal records shared across suites). Table~\ref{tab:main_benchmark} reports $95\%$ marginal bootstrap CIs ($1{,}500$ resamples); contrasts use normal-approximation two-sided paired Wilcoxon signed-rank tests (zero-differences omitted) with Holm-Bonferroni correction ($30$-test family in RQ2; $4$-test family in RQ5), $2{,}000$-resample paired bootstrap differences, and Cliff's $|\delta|$, conditional on the three OSS traces. Descriptive 20-seed A/A noise (\texttt{v4\_exp1\_aa\_noise}) is \AANoiseThroughputPct{}\% throughput, \AANoiseLatencyPct{}\% P95, and \AANoiseComputePct{}\% cost.
