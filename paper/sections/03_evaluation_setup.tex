\section{Evaluation Setup}
\label{sec:eval_setup}

\subsection{Executable Multi-PR Causal Blame Micro-Benchmark}
To ground causal blame accuracy and latency empirically rather than assuming synthetic numbers, we construct an executable six-module Python repository (\texttt{pricing}, \texttt{inventory}, \texttt{shipping}, \texttt{auth}, \texttt{ledger}, \texttt{checkout}) with integration tests and evaluate \BenchTotalBatches{} failing multi-PR batches (sizes 4--8 PRs) executed via real subprocess \texttt{unittest} runs:
\begin{itemize}
    \item \textbf{\BenchSingleBatches{} Single-PR Functional Regressions}: 12 distinct functional bugs across all modules combined with real functional-AST benign PRs (guards, refactors, zone additions---not comment-only diffs).
    \item \textbf{\BenchSemBatches{} True Pairwise Semantic Conflicts}: 6 cross-file conflict pairs verified by automated unit tests to satisfy \emph{individual pass, combined fail} (PR $A$ passes alone, PR $B$ passes alone, $A+B$ fails integration tests due to rounding drift, in-place mutation vs.\ immutability assertion, whitespace trimming mismatch, strict typing, or bracket thresholds).
\end{itemize}

\subsection{Real OSS PR Traces and Decoupled Conflict Oracle}
We collected 600 chronologically merged PRs via GitHub GraphQL (200 each from \texttt{kubernetes/kubernetes}, \texttt{microsoft/TypeScript}, and \texttt{vercel/next.js}; file lists capped at 40 files/PR by GraphQL pagination). Table~\ref{tab:trace_summary} reports each repository's unique files, hotspot Gini concentration, FIFO-8 overlap rate, and disjoint-4 batch feasibility. The earliest $25\%$ ($150$ PRs total) build $\hat{G}$; the remaining $75\%$ ($450$ PRs) drive the evaluation stream, preserving real relative inter-arrival gaps scaled to $6.0\times v$ PRs/hr ($v \in \{1\times, 3\times, 5\times, 10\times\}$).

Crucially, to eliminate circularity between conflict injection and SSMQ's graph-disjoint batcher, our v2 simulator separates the \emph{ground-truth conflict oracle} $G^*$ from the scheduler's observed graph $\hat{G}$ via \texttt{graph\_recall} $\rho \in [0.40, 1.00]$. At our default $\rho = 0.80$, approximately $20\%$ of all injected semantic conflicts are \emph{off-graph latent edges} outside $\hat{G}$ that SSMQ cannot foresee. Furthermore, $3\%$ of conflicts are designated \emph{persistent} against the cumulative mainline tree (failing even after sequential rebase), while the remaining $97\%$ represent rebase-resolvable intra-batch interference. Individual PR defects are calibrated to mean $8\%$ risk-weighted rate, CI workers $W=8$, build times $\mathcal{N}(12.0, 2.0^2)$~min, and SSMQ's blame ranker is parameterized strictly by the micro-benchmark measurements (\BenchASTTopOnePct{}\% Top-1, \BenchASTMs{}~ms).

\subsection{Baselines, Sealed Lineage, and Paired Inference}
We compare \textbf{SSMQ} against five baselines and three ablations: \texttt{SerialQueue}, \texttt{StaticBatchBisect} (Bors/GitHub style~\cite{fallahzadeh2023accelerating}), \texttt{SpeculativeLinear} (GitLab/Mergify style), \texttt{UberSubmitQueue} (a faithful EuroSys~'19 outcome-tree planner~\cite{ananthanarayanan2019keeping} ranking both pass and fail speculative branches by expected merges per CI minute), \texttt{FlakeAwareBatch} (unconditional single retry prior to bisection~\cite{henderson2023flake}), and ablations \texttt{SSMQ-NoGraph}, \texttt{SSMQ-NoFlaky}, and \texttt{SSMQ-NoBlame}.

All \TotalSealedRuns{} v2 suites (\TotalSealedRecords{} simulation records + \BenchTotalBatches{} executed blame batches) run across 20 paired seeds per repository with identical defect/conflict ground truth per `(repo, seed)`, sealed with git commit SHA and full harness/dataset/artifact SHA-256 verification. Our zero-LLM auditor computes matched paired contrasts, $95\%$ bootstrap CIs, and two-sided Wilcoxon signed-rank $p$-values with Holm-Bonferroni correction. Disjoint 20-seed A/A calibration (\texttt{v2\_exp1\_aa\_noise}) confirms seed-block stability of \AANoiseThroughputPct{}\% throughput, \AANoiseLatencyPct{}\% P95 latency, and \AANoiseComputePct{}\% compute cost.
