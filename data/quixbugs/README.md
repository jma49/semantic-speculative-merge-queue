These six Python algorithm implementations, their faulty counterparts, and their JSON test vectors are unmodified copies from [QuixBugs](https://github.com/jkoppel/QuixBugs/tree/4257f44b0ff1181dedaedee6a447e133219fcebf). The upstream license is included. The selection is a convenience sample of self-contained algorithms with native scalar or list outputs that use neither graph nodes nor generators. The evaluation adapter combines their function bodies in one file, preserves each test vector, and supplies controlled neutral edits. These combinations are constructed; the individual faults and test vectors originate upstream.
